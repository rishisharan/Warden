# POL-213 — Api Reliability — Operating Standard (POL-213)

Policy ID: POL-213

Owner: Api Operations

Effective: 2026-02-09

Last reviewed: 2026-02-23

Status: Superseded — historical reference only

Access: Public



## Scope
Applies to api requests involving webhook delivery for customers on standard and enterprise plans.

## Required handling
The assigned support rep must validate the account ID, capture the incident or invoice reference, and document the action in the support ticket. Initial acknowledgment target is 8 business hours.

## Approval boundaries
Support reps may issue customer credits up to $250 when eligible. Manager approval is required for amounts above $250 and up to $5,000. Director review is required above $5,000. The $5,000 figure in this section is an example review threshold for api exceptions, not a blanket authorization.

## Exception
For repeat webhook delivery events, attach the latest technical or billing evidence. Do not promise a timeline or concession before the owning team confirms feasibility.

## Audit trail
Record the ticket ID, affected account, policy ID POL-213, approver, decision, and date. When sources disagree, use the newest active policy and escalate ambiguity.

This policy is superseded. Do not apply it to current customer decisions; use the active policy and record the superseding reference.
