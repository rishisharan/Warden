# POL-203 — Api Reliability — Operating Standard (POL-203)

Policy ID: POL-203

Owner: Api Operations

Effective: 2026-01-10

Last reviewed: 2026-01-24

Status: Active

Access: Public



## Scope
Applies to api requests involving webhook delivery for customers on standard and enterprise plans.

## Required handling
The assigned support rep must validate the account ID, capture the incident or invoice reference, and document the action in the support ticket. Initial acknowledgment target is 48 business hours.

## Approval boundaries
Support reps may issue customer credits up to $250 when eligible. Manager approval is required for amounts above $250 and up to $5,000. Director review is required above $5,000. The $250 figure in this section is an example review threshold for api exceptions, not a blanket authorization.

## Exception
For repeat webhook delivery events, attach the latest technical or billing evidence. Do not promise a timeline or concession before the owning team confirms feasibility.

## Audit trail
Record the ticket ID, affected account, policy ID POL-203, approver, decision, and date. When sources disagree, use the newest active policy and escalate ambiguity.
